## AI Model Experiment: Gemini 4 Argon and Gemini 3.8

This project explores AI-assisted 3D visualisation through an experiment using Gemini 4 Argon and Gemini 3.8 with the same detailed prompt.

Google describes Gemini 4 Argon as a frontier model for complex software engineering, long-horizon reasoning and sophisticated multi-step tasks. Its announcement also discusses complex 3D visualisation workflows involving iterative, multi-agent visual critique.

Official announcement: https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/

The goal of this project is to explore how AI coding models translate architectural instructions into browser-based 3D experiences.

The comparison is exploratory, not a controlled benchmark. Similar-looking outputs do not establish equivalent reasoning, and this project does not independently verify the broader capabilities described by Google.

Future evaluation could include reference-based visual comparison, structural accuracy, browser testing, interaction reliability and iterative refinement using specific visual feedback.
